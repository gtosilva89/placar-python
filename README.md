# Reino da Lógica

Jogo em pixel art de lógica de programação e Python para o 1º ano do ensino médio (Técnico em IA, Senac PR).

**Jogar:** https://gtosilva89.github.io/placar-python/

- O aluno entra com o nome e salva por um **código de salvamento**, que deve anotar no caderno.
- Para continuar outro dia, em qualquer computador, ele digita o mesmo nome e o código.
